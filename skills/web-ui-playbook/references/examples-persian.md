# Persian & Iranian Reference Examples

Name 1–2 of these in every Persian build ("Reference: Sabzlearn — copy its dark-mode course card"). Copy **patterns**, never branding or assets.

Merged from the two Persian catalogs (reports D/E), deduplicated, with a live spot-check on 2026-10-14. ⏱ Site designs change and campaign pages get retired — **verify the page before citing a detail**.

**Status:** ✓ = listed in both reports · ⚠ = one report only · ❓ = conflicting or failed the spot-check.
**Access:** all `.ir`/Iranian sites were reported as reachable inside Iran without a VPN ⏱. Medium, Dribbble and Behance need a VPN from Iran.
