## 1. Quick pick
| Project | Look at first |
|---|---|
| SaaS landing + pricing | Vercel (pricing calculator, hairline grid), Linear (restrained dark craft), Clerk (live component in hero) |
| Dashboard / admin | Attio (light dense tables, inline edit), Dub.co (filter chips), Ramp (detail side sheet), Retool (dense data grids) |
| Language school / courses | Duolingo (tactile buttons, streaks, single path), Brilliant (interactive in the first 10s), Frontend Masters (syllabus, learning paths), Coursera (faceted search) |
| E-commerce | Gymshark (quick-add sizes), Allbirds (sticky add-to-cart, cart drawer), SSENSE (3-column sticky PDP), Aesop (sensory attributes) |
| Fintech / trust | Wise (working calculator as the hero), Stripe (every claim paired with a UI miniature) |
| Blog / editorial | Stripe Press, NYT, The Pudding |
| Booking / scheduling | Cal.com (availability builder as toggleable day rows) |
